## Tech Stack

- **Static HTML** with the [Broadsheet design system](/_ds/)

- **No framework** — vanilla HTML, CSS, and JS

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build → dist/
npm run build

# Preview production build locally
npm run preview
```
